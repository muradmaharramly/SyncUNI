- SyncUNI — Data-Driven Career Intelligence Ecosystem
SyncUNI, təhsil müəssisələri ilə sənaye arasındakı boşluğu dolduran, rəqəmsal olaraq doğrulanmış dataya əsaslanan karyera idarəetmə platformasıdır. Tələbələrin real bacarıqlarını süni intellekt analitikası ilə birləşdirərək, işə qəbul prosesini tamamilə avtomatlaşdırır.

- Əsas Özəlliklər
- AI-Powered CV Summary (Pollinations.ai)
Platforma, tələbənin profili, GPA göstəriciləri və texniki bacarıqlarını analiz edərək text.pollinations.ai vasitəsilə fərdiləşdirilmiş, professional CV Summary mətnləri generasiya edir. Bu, namizədin ən güclü tərəflərini HR mütəxəssislərinə bir neçə cümlə ilə effektiv şəkildə təqdim edir.

- Intelligent AI Agent & Real-time Automation
Platformanın mərkəzində dayanan AI Agent sistemi:

Məlumat Analizi: Mövcud tələbə və şirkət datalarını anlıq skan edir.

Smart Notifications: Tapılan uyğunluqları önəmlilik dərəcəsinə görə (High/Medium/Low) təsnif edərək bildiriş panelinə göndərir.

Market Insights: Bazardakı aktiv vakansiyaları və trend olan bacarıq tələblərini analiz edərək, həm tələbələrə, həm də universitetlərə tövsiyələr verir.

- Dinamik Data İnteqrasiyası (JSONBin.io)
Bütün ekosistem datası (tələbələr, şirkətlər, universitetlər) JSONBin.io üzərində bulud formatında saxlanılır. API açarı (X-Master-Key) ilə qorunan bu infrastruktur, məlumatların real vaxt rejimində təhlükəsiz şəkildə oxunmasını və yenilənməsini təmin edir.

-Quraşdırılma (Installation)
Repozitoriyanı klonlayın:
git clone https://github.com/yourusername/syncuni.git

Dependecy-ləri quraşdırın:
npm install

Layihəni başladın:
npm start

-Layihə Strukturu
src/
├── components/       # UI komponentləri (Bento Cards, Sidebar, Agent)
├── styles/           # SCSS modulları və qlobal dizayn qaydaları
├── services/         # API (JSONBin) və AI (Pollinations) servisleri
├── hooks/            # Custom hooks (useFetch, useAIAgent)
└── context/          # Role-based access control (Global State)
